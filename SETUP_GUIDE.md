# Setup guide

This guide will be filled in during implementation.

Phase 1 target environment:

- Windows
- local Excel installed
- Python installed
- `openpyxl` installed
- `pywin32` installed or installable with:

```powershell
py -m pip install pywin32
```

The normal user workflow should happen inside the desktop app. PowerShell should only be needed for setup or troubleshooting.
